# Contributing

This repository is a **build artifact**. Its files are generated by the
maintainers' source repository on every release, and the installed copy is
verified against `MANIFEST.sha256`, so a pull request cannot be merged here as
it stands.

What helps:

- **Issues are welcome.** Open one for a bug, a confusing step or a feature
  idea. Include the output of `run qa-doctor` in your editor, your OS and your
  editor name and version.
- **Suggested changes** can be described in an issue or sent as a pull request
  for reference. A maintainer re-implements accepted changes in the source
  repository, and they ship in the next release.
- **Security problems** go through [SECURITY.md](SECURITY.md), not a public
  issue.

The source is visible for transparency; see [LICENSE](LICENSE) for the terms.
